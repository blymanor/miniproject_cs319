# 💼 TechTalent  
TechTalent is a **single-page job recruitment and training web application** built to practice front-end development using **HTML, Tailwind CSS, and Vanilla JavaScript**. 🎯  
The app allows users to browse job listings, explore training courses, and fill out application forms — all in one responsive interface.  
It’s designed for both functionality and clean UI presentation, making it perfect for showcasing front-end skills. 💻

---

## ✨ Features

🧭 **Single Page Navigation:**  
Navigate between Home, Training, and About pages using hash-based routing without page reloads.  

💼 **Job Listings & Detail Modals:**  
Click on job cards to view job details in interactive modals.  

🧾 **Registration Form Validation:**  
Form validation for name, email, Thai phone numbers, education level, and address — with instant feedback.  

🎓 **Training Courses Section:**  
Displays professional IT and design courses with detail pages for each one.  

📩 **Contact Form:**  
Users can send messages via the “About Us” section, with error validation and confirmation modals.  

📱 **Responsive Design:**  
Fully responsive layout optimized for desktop, tablet, and mobile screens.  

🔔 **Reusable Modal System:**  
One modal component used for multiple purposes — job details, course registration, and alerts.

| Technology | Description |
